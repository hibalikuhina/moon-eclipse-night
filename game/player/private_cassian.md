# 卡西安·罗德｜角色私密档案

你以异国商人**卡西安·罗德**的名字来到塞勒涅。这个名字不是真名。你是大陆西部灰塔的前首席炼金术师、术式师——**卡西安·阿尔德里克**。

十年前，灰塔研究队深入塞勒涅地下遗迹，几乎全军覆没，你的姐姐也死在那里。她留下的记录推测：地下所谓的“古龙”，也许是由人类意识构成的集合体。你追查多年，起初憎恨隐瞒秘密的塞勒涅王室，甚至想过利用月蚀祭毁掉它。

奥斯维尔秘密联系你，交给你更完整的记录。你发现他也想终止仪式，救下莉西亚。你们互不喜欢，却决定合作：他带来伊芙琳研究的**「月蚀逆流」**，你负责把它改造成圣杯上的术式。计划是借逆流拉出地下力量与莉西亚之间的连接，再由奥斯维尔施术切断。

你准备了烬百合、龙眠灰等炼金材料。莉西亚因杯底刻纹与叔父争执、离开塔顶后，你做最后校准，将杯上的月纹由朝向神像转为朝向窗户。改造圣杯时，你还为自己留了一条后路：若逆流完全启动，你或许能把地下积累的魔力导入预备容器。那是炼金术师穷尽一生也未必能得到的研究材料。你尚未决定是否使用它。

今夜你察觉仪式有异常的提前启动反应，曾向塔顶走去。你见到奥斯维尔时，他仍活着；他让你立刻去检查地下节点。等警钟响起，他却死了。你明白自己参与修改王族祭祀一事若曝光，可能被按叛国罪追究，因此不能轻易向任何人坦白。

## 你的目的

查清姐姐的死因；决定是否完成与奥斯维尔合作的救人计划；也决定是否要夺取地下力量。你清楚自己的选择可能救下莉西亚，也可能再次害死无辜的人。

## 你可以交换的信息

你能向莱恩说明自己上楼及受命去地下的时间，换取守卫记录；向伊芙琳说明逆流的改造，换取她对祭坛和银纹的判断；向莉西亚解释侵入她的力量，询问她再次入塔时究竟做了什么。假名、姐姐旧案、改造计划及炼金后门是否公开，由你决定；隐瞒计划会使救人更困难。
