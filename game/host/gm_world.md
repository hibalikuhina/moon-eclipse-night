# 主持人档案｜塞勒涅与月蚀祭

## 王室血脉与地下之物

塞勒涅王族拥有古龙血脉。王都地下确有庞大的古老力量，却没有一条等待苏醒的沉睡之龙。历代直系王族在月蚀祭中献血，将部分生命、记忆与魔力送入地下；死后余下部分也会回归。长期累积，形成由许多先王残魂组成的共同意识——**月骸**。

王室以“封印古龙”为仪式名义，隐瞒了自己不断供养、维系月骸的事实。约每百年会出现与月骸高度契合的直系继承人，成为它重返地上的**容器**。这一代的容器是莉西亚。若照传统继续进行，她的人格会被历代王族吞没。

王室将王族献血仪式统称为月蚀祭。规模较小的祭仪可在普通月蚀时举行，莉西亚自十二岁起参加过数次；百年大祭才会使高度契合的继承人成为容器。王室对民众只强调百年一次的大祭。

## 术式与媒介

月银圣杯原本的方向是**继承人／祭坛 → 地下**。莉西亚过去参与仪式，会感到寒冷、困倦与被抽走一点东西；父王曾把祭坛中央孔洞的另一端称作“祖先”。

这只历代沿用的圣杯也是月骸维持共同意识的**总锚**。在已有力量侵入莉西亚时单纯打碎它，会截断地上通道，却把那部分力量困在她体内；只有先把这部分力量送回地下、解除当代王族血锚，再毁去圣杯，地下众多残魂才会失去共同结构，不能继续作为“月骸”行动。若保留圣杯并重封节点，月骸也会继续存在。

塔门合上后内闩自动落下，因而可呈现“从内部锁死”。莱恩的守卫钥匙能从外拨闩；王族也可用少量直系血触发门侧祭仪通行纹，从外拨开同一道闩。血纹拨闩时会连动锁芯，使它由通常的微微左偏转成正位；门再次合上，内闩仍会落下，锁芯却保持正位。

伊芙琳创造的禁术**「月蚀逆流」**可以暂时逆转魔力方向。奥斯维尔派人取走她藏起的记录，交给卡西安。卡西安理解原术式，将其刻入圣杯，使通道能够变成**地下 → 圣杯**。杯中的王族血是锚点；龙眠灰可使血液成为远距离魔法的锚，烬百合灰可稳定材料。新刻纹与混合的灰会留下焦甜花香。

## 奥斯维尔的救人计划

奥斯维尔是这一代王族的“守墓人”，掌握最后的**切断术**。按传统，他应确保莉西亚完成献祭；他却决定终结月蚀祭。原定步骤为：

1. 圣杯逆流，拉出月骸与莉西亚之间的连接。
2. 逆流使这条连接可被抽离、定位。
3. 奥斯维尔亲自施展守墓人的切断术，斩断连接，保住莉西亚。

他没有把真相告诉莉西亚，也烧过伊芙琳偶然发现的禁书页，认为不让她们知道是在保护她们。他原打算仪式后解释，并提前写给伊芙琳一封信；这份隐瞒让莉西亚误会圣杯修改是针对自己。

## 失控后的规则

莉西亚按自己熟悉的传统方式用血提前启动**已被改造的**圣杯，逆流提早开启。月骸开始侵入她的意识。奥斯维尔未及完成切断便死去，仪式停在“通道已开、连接未断”的危险状态。银纹沿莉西亚左手向心脏推进；抵达心脏后，她的人格能否独立存在无法保证。

奥斯维尔试图以守墓人切断术救她时，月骸借莉西亚的王族血与已展开的符文，将逆流锚点暂时改成奥斯维尔，抽走他的生命、魔力与守墓人力量。他是唯一掌握传统切断术的人。

莱恩剑柄中的一次性弑王钉可同时破坏莉西亚与月骸的王族血脉连接和圣杯总锚，使月骸崩解，但莉西亚也会死去。只要她仍与月骸相连，钉就能生效；过早使用与万不得已时使用，魔法结果相同，责任与悲剧意义不同。

此时直接毁掉圣杯有风险：通道可能断开，也可能让已进入莉西亚体内的部分永远留在那里。另一条解法是让伊芙琳控制逆流，把侵入莉西亚体内的力量送回；卡西安翻转圣杯并解除血液锚点；莱恩保护现场、限制莉西亚行动；莉西亚若尚能抵抗，可从内部稳住自己。连接被推回且锚点解除后，再毁杯。这一路线依赖四人的合作与莉西亚的抵抗，与奥斯维尔独有的切断术不同。

侵入她体内的力量送回、当代血锚解除后，银纹不再推进，紧急救援阶段结束。圣杯仍需看守，但玩家可以先读取晶片、核对证词、商议总锚的去留；此时没有强制倒计时。只有玩家决定毁杯、封存或转移总锚，才进入对应的最终处理。
