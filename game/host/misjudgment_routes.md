# 主持人档案｜误判路线

案件的正确结论是：莉西亚用血提前启动圣杯，但并无杀害叔父之意；月骸借她的身体与奥斯维尔已展开的守墓人术式，抽空了奥斯维尔。**犯错的推理和有罪的行为不是同一回事。**玩家可以误指卡西安、伊芙琳、莱恩，也可能认定莉西亚清醒谋杀；最终后果取决于他们为此采取了什么行动。

## 误判如何推进

1. **提出猜测：**允许任何指认。被指认者只回应自己当时知道的事；主持人不代替玩家判对错。可查的反证仍留在圣杯血迹、门侧通行纹、奥斯维尔掌心符文、披肩、银纹流向和记忆晶片中。
2. **作出行动：**拘禁关键协作者、先砸圣杯、拒绝分享术式、等待审判或放弃抵抗，才会实质改变局面。错误指认本身不令银纹瞬间抵达心脏，也不强迫其他人服从。
3. **给出警讯：**莉西亚的银纹从手腕延至手臂、肩口、胸前时，依次让现场人物看见或感到变化。每次无法及时撤回的错误行动或重大拖延后推进一段；正常交谈、重新检查证据不因此受罚。到胸前时明确告知这是最后的救援窗口。
4. **结算结果：**若玩家改判并及时取得合作，仍可进入「断月」等救人结局。若自愿接纳月骸，用「新月女王」；若未同意却失救，用「空冠」。若先毁杯，用「残月囚身」；若莱恩使用弑王钉，用「弑王者」，并区分最后手段与过早使用。这些结局的正文见[可能的结局文案](ending_scripts.md)。

## 莱恩视角：把会救人的人当作凶手

**常见错判：**卡西安携带烬百合与龙眠灰、改造圣杯，又曾在案发前上楼，因此必是他杀了奥斯维尔；或认为塔门只有钥匙能开，自己离岗是唯一机会。

**可得反证：**卡西安上楼时奥斯维尔仍活着；地下节点留有他案发时检查的痕迹。门侧血纹能拨开内闩，莉西亚的披肩与尸体旁布料相合。莱恩若请求伊芙琳检查银纹，会发现杀人者与受侵入者之间的联系。

**若坚持执行：**莱恩把卡西安关起来、扣下他的炼金器材，伊芙琳即使稳住逆流，也失去能解除圣杯血锚的人。若仍拒绝释放他或寻找同等可行的操作，银纹抵达心脏，接「空冠」；莱恩使用弑王钉，则接「弑王者」，并说明当时是否仍有救援机会。若他改判并请卡西安回到圣杯前，救援仍可继续。

**进入失救结局前可宣读：**

> 莱恩守住了塔门。被他认定为凶手的人没有再靠近圣杯。直到伊芙琳喊出“锚点还在”，他才发现自己守住的是一扇门，挡住的却是最后一个能把莉西亚带回来的人。

## 伊芙琳视角：把术式来源当作杀人过程

**常见错判：**卡西安掌握她失窃的逆流、身上有焦甜花香，故他亲手用圣杯抽空奥斯维尔；既然圣杯是凶器，立刻毁杯就能救莉西亚。

**可得反证：**杯中的血属于莉西亚；奥斯维尔掌心的切断符文尚未画完；卡西安离开塔顶去检查节点时奥斯维尔仍活着。莉西亚的银纹仍在进入身体，奥斯维尔的银纹却指向力量被抽走。毁杯前能先检查血锚和回送路径。

**若坚持执行：**若伊芙琳在莉西亚体内仍有月骸力量时先毁杯，接「残月囚身」；若只拘禁卡西安、拒绝他的校准知识又任血锚维持，则可能接「空冠」。她可在最后一刻停下毁杯，要求卡西安解除锚点，再改走救人路线。

**进入残月结局前可宣读：**

> 伊芙琳终于找到了自己的禁术，也找到了刻在杯底的手。她举起圣杯时，以为摧毁凶器就能结束这一切。莉西亚却在她身后叫了一声：那声音有一半属于她，另一半还留在杯与血之间。

## 卡西安视角：用自己知道的秘密填满未知

**常见错判：**伊芙琳创造逆流又秘密入塔，因此她可能在卡西安离开后返回杀人；或者莉西亚主动启动圣杯，便等于她清醒地谋杀叔父。卡西安虽然知道自己的改造计划，却不知道后半段杀人发生时莉西亚的意志状态。

**可得反证：**伊芙琳的脚步与卡西安上楼时间相合，不在莱恩取银烛的谋杀窗口；尸体与莉西亚银纹方向相反，晶片里莉西亚曾求叔父救她。莱恩的守卫记录、披肩与门侧血纹能补全卡西安缺少的后半段时序。

**若坚持执行：**卡西安为保住自己的秘密，将伊芙琳定为凶手而拒绝向她说明逆流三步，或把莉西亚当作自愿容器、拒绝解除血锚；仅靠他的炼金操作无法控制回送，拖延到心脏则接「空冠」。若他趁众人相互怀疑启用后门，接「骗子的胜利」。他若坦白改造并与伊芙琳交换时间线，仍可救人。

**进入失救结局前可宣读：**

> 卡西安把每一条术式都算得精确，却把空白处填成了自己最愿相信的答案。他知道杯子是谁改的、灰是谁带的，却始终没有问莉西亚：抬手杀人之前，她究竟说了什么。

## 莉西亚视角：把受控当成自己的意愿

**常见错判：**她发现自己用血启动圣杯、披肩碎片又在叔父身旁，便认定自己清醒地杀了他；或因卡西安改造圣杯，认定他才是谋害叔父的人，拒绝他的帮助。两者都会使她停止寻找自己缺失的那几息。

**可得反证：**掌心符文说明叔父正试图切断连接；晶片中她曾求救；自己的银纹由外向心脏进入，而叔父的银纹是力量被抽走。她可以请伊芙琳陪同读取晶片，也能让莱恩核对银烛与塔门时序。

**若坚持执行：**若她以“我本来就有罪”为由拒绝救援、任月骸夺走身体，接「空冠」，不能把这解释成她主动接纳月骸。只有在知道同化代价后明确选择接纳，才接「新月女王」。若她请求莱恩用弑王钉，莱恩仍须自行决定；无论当时是否还有其他解法，使用后都接「弑王者」，并区分是否过早。她若允许别人检查记忆与银纹，救援仍有机会。

**进入失救结局前可宣读：**

> 莉西亚把碎片握在掌心。它证明她曾在叔父身边，却没有告诉她那时是谁在驱使她的手。她说“是我”，塔下的声音便顺着这句话答：“是我们。”她若不再争辩，月光会慢慢把两句话合成同一个声音。

## 指认错误但仍救下莉西亚

若玩家曾错指凶手，却及时听取反证并救人，不使用上述失救段落。结局复盘可以保留这次错误：被冤指的人是否原谅、公开记录如何写，由玩家与角色决定。错误推理不抹去后来作出的正确选择。
