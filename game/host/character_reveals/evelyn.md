# 伊芙琳｜游玩中可逐步揭示的非公开情报

## 开局只属于伊芙琳的认知

伊芙琳三年前在禁书库看到“并非为了使龙沉睡”“王族之血”“容器”等残句，之后目睹奥斯维尔烧书。她曾创造可以逆转魔力方向的禁术「月蚀逆流」，记录两周前失窃，连莱恩都不知道。午夜前她秘密入塔检查圣杯，只辨出部分转移术式；逃离时听到脚步、闻到烧焦花香。现场月相魔法残留使她容易被怀疑。

## 随调查可确认的事

1. **检查圣杯：**新刻纹使用「月蚀逆流」的关键结构，且被真正理解原理的人修改过；花香、血和灰将术式与炼金材料联系起来。
2. **检查血液与祭坛：**杯中血更像莉西亚的直系王族之血，龙眠灰令它成为锚点；祭坛孔洞长期由上向下输送，当夜却出现强烈逆流，深处有大量彼此回应的魔力。
3. **检查银纹：**莉西亚的纹路仍有魔力，沿左手向心脏进入；奥斯维尔的纹路方向相反、身体被抽空。两者并非同一受害状态。
4. **与卡西安交换情报：**她才得知奥斯维尔派人偷走研究，由卡西安把它改造成救莉西亚的圣杯术式；地下不是沉睡古龙，而是历代王族的共同意识。
5. **复查尸体：**奥斯维尔掌心有未完成的切断术、记忆晶片，身边有被扯下的金纹布料。解析晶片可见莉西亚先求叔父救她，随后神情改变、抽走他的力量；布料属于莉西亚的仪式披肩。

银纹逼近心脏时，她可以先尝试救莉西亚，事后再解析晶片和布料；不必把读出最终证据设为救人的前置条件。

## 更晚才可能知道

奥斯维尔暗中关注过伊芙琳的研究，正是看到她创造逆流，才相信月蚀祭可能被终结。他原计划事后解释，并在书房一本税务账册中留下信。若搜索书房，伊芙琳可读到他承认应由她自己选择是否知道真相；这并非她开局已知的养父心意。

## 信息公开的边界

她可以选择向莱恩坦白自己的禁术与秘密入塔经历，也可以与卡西安交换调查结果。她的魔法能力让她更容易验证流向，却不等于开局就知道凶手、月骸或奥斯维尔的计划。
