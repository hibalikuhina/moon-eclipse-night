# 卡西安｜游玩中可逐步揭示的非公开情报

## 开局只属于卡西安的认知

“卡西安·罗德”是假名。他是灰塔前首席炼金术师**卡西安·阿尔德里克**，多年追查姐姐在塞勒涅地下遗迹的死亡。姐姐遗留的记录提出地下并非普通沉睡古龙，而可能有由人类意识构成的集合体。奥斯维尔交给他更完整的记录，两人合作改造圣杯，企图把莉西亚与地下意识的连接拉出、切断。

卡西安知道奥斯维尔提供了伊芙琳失窃的逆流研究，自己使用了烬百合和龙眠灰。他还瞒着奥斯维尔留下一个把月骸力量导入预备容器的后门。参与修改王族祭祀可能被当作叛国，他有理由隐瞒，即使他不是凶手。

他午夜前曾向塔顶走去；当时奥斯维尔仍活着，后来命他去检查地下节点。这是卡西安可为自己提供的关键时间线，但他初期不愿连带暴露合作计划。

## 调查中可能公开的层次

1. **烬百合与脚步：**他可承认自己持有这种花、知道炼金用途，也确曾在伊芙琳离塔时上楼。此时仍可回避真实身份和完整计划。
2. **情报交易：**当伊芙琳提出足够准确的术式与仪式判断，他可承认奥斯维尔盗取研究、自己改造圣杯，以及计划的目标是救莉西亚。
3. **月骸真相：**他能解释历代王族的意识如何积累、莉西亚为何是容器，以及逆流—抽离—切断三步。若知道莉西亚已听见声音、银纹正在蔓延，他会意识到同化正在发生，需要伊芙琳帮助。
4. **真实身份与姐姐：**若主动坦白，或有人将其随身灰塔印记与封存事故卷宗比对，其他人才会知道他的真名与长期动机。姐姐留下的残页、节点刻痕和封存记录互证：她为同伴维持撤离通道，死于节点封闭前的魔力冲击；王室隐瞒事故，奥斯维尔并未亲手谋杀她。
5. **炼金后门：**仅卡西安本人开局知道。要让他人知道，需他自行承认、有人检查并理解预备容器上的导入纹，或他实际启用它。

## 终局选择

卡西安可协助其他人救回莉西亚，也可趁逆流完全启动夺走月骸力量。若他从姐姐旧案得知王室的隐瞒与奥斯维尔并未直接杀人，仍须亲自决定是否借新的危险力量追究旧责。
