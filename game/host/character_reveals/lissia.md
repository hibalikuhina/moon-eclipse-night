# 莉西亚｜游玩中可逐步揭示的非公开情报

## 开局的破碎记忆

莉西亚记得自己发现圣杯的新刻纹，与叔父争吵；后来独自返回塔顶，碰到祭坛旁的灰。她知道王族可用血触发塔门石纹，但记不清今夜是否用了。她自十二岁起参加过几次小祭，今夜的百年大祭却不同。再往后的记忆断掉。她醒过神时，奥斯维尔已死，左手有银纹，脑中有声音叫她“回来”，又说“不要相信守墓人的孩子”。若玩家选择莉西亚，**不能在此时直接告知她自己是凶手**。

她隐约记得奥斯维尔抓住自己衣服、叫她“醒醒”；自己哭了，手似乎抬起来。画面尚不足以确认是谁杀了他。她恐惧失去自我，也怕真凶是自己。

## 交谈与检查会揭示什么

1. **回忆准备仪式：**她与奥斯维尔一起布置圣杯、银烛和祭服；叔父拒绝解释为何今年多了刻纹，还告诫她别碰圣杯。她后来第二次进入时，圣杯月纹已由朝神像变成朝窗。
2. **检查手套下的伤：**左手银纹仍有魔力，沿手臂向心脏流动，与奥斯维尔尸体上失去魔力的银纹不同。症状加剧时，她会听见更多重叠的声音。
3. **追问声音：**她能描述“血已经回来了”“门正在打开”“回来，成为我们”，并看到不同时代王族生前与死后的记忆。声音称奥斯维尔为“守墓人”。她可逐渐理解所谓祖先并非比喻。
4. **回想自己的第二次入塔：**她最终应面对自己当时不只碰了灰，还**用自己的血主动启动圣杯**。她起初只模糊觉得自己还做过什么，并因恐惧不愿深想。杯中血、掌心伤、通行纹和逆流痕迹可逐步拼回这段。
5. **记忆晶片与布料：**布料来自她的仪式披肩，说明她在奥斯维尔死亡时近身。晶片展示她哭着求“叔叔……救我”，下一刻神情改变并抽走他的力量。这时才能明确区分：身体实施了杀人，**她本人没有主动谋杀的意图**，月骸曾短暂控制她。

## 对自身身份的最终选择

月骸会用历代王族的知识、记忆与强大王权诱惑她，称这不是死亡而是继承。莉西亚可以拒绝它，继续作为只有十九年记忆的自己活下去；也可主动完成仪式，保留一个名为“莉西亚”的部分，却成为众多人格之一。这是终局选择，不能回填到开局卡里。

## 对外证词的边界

她确实碰过灰、听见声音，并非整段证词都虚构。她对启动圣杯的回避与受侵蚀的记忆交织，无法完整叙述杀人时的动作。其他角色需结合银纹、圣杯、银烛、披肩和晶片逐步判断，不能仅凭她的沉默就认定她清醒地谋杀叔父。
