# 莱恩｜游玩中可逐步揭示的非公开情报

## 开局只属于莱恩的认知

奥斯维尔是他的养父，莱恩真心敬重他。案发前奥斯维尔命他：仪式若有意外，无论莉西亚怎样要求，都不能让她离开祭祀塔。奥斯维尔还留下另一道条件命令：若自己死亡且莉西亚开始表现异常，莱恩必须打开剑柄暗格。莱恩此时**不知道暗格中的物品是什么或为何需要它**。

莱恩记得正式封塔前的访客，也知道自己曾因莉西亚所说的“少一支银烛”离岗五六分钟。回来后锁芯的位置变了；这些事可由他在询问下说出。手套前后不同的细节，需要他重新回忆才意识到。

## 触发剑柄暗格

**明确条件：**奥斯维尔已死，莉西亚出现异常。莱恩若依命打开暗格，便会找到一枚一次性**弑王钉**。它能够破坏古龙血脉。结合莉西亚被月骸同化的危险，莱恩会理解奥斯维尔交给自己的最后手段：若无法救回她，就亲手杀死她，以阻止月骸借容器苏醒。奥斯维尔事先没有解释原因。

其他角色不能仅凭莱恩带剑，就知道暗格或弑王钉的存在；需由莱恩取出、告知，或在他交出剑接受检查后才会公开。

## 抉择时的信息边界

莱恩可以在月骸真相逐渐显露时，先尝试保护莉西亚、协助伊芙琳和卡西安完成救援。弑王钉能终结月骸，但代价是莉西亚的生命；过早使用会错过本可成功的救援。它不是莱恩开局已知的结论。

## 其他人可能发现什么

- 伊芙琳可从哥哥的异样与奥斯维尔的命令得知他另有负担，但暗格内容仍须触发。
- 莉西亚可察觉莱恩在留意自己的异常，不会自动知道他有杀死自己的手段。
- 卡西安可推测奥斯维尔留有最后保险，却没有被明示剑柄内容。
