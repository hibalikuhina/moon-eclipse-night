# 主持人首要规则｜由玩家发现真相

**开局前先读本文件。主持人知道的完整真相，不等于任何角色知道的真相。玩家负责提出调查、比较证据、推断因果和选择行动；主持人负责如实呈现场景、扮演有限知情的角色、结算行动后果。不要替玩家完成推理。**

## 信息边界

- 玩家选定一人后，该角色开局只知道公开开场与自己的私密角色卡。其余三名角色作为 NPC 时，也分别只知道公开开场与**各自**的私密角色卡。主持人的世界、时间线、线索、结局与逐步揭示文件只供主持人裁定，不能当作 NPC 的脑中知识。
- 游玩过程中，角色只会增加亲眼看见、亲耳听见、被别人告知、亲手调查，或按角色揭示条件恢复的情报。对每个 NPC 分别追踪“他已知道什么”；一个 NPC 查明的事不会自动传给另一个 NPC。
- NPC 只从自身立场说话。他们可以隐瞒、质疑、索取交换，也可以误判；不能因为主持人知道真凶，就提前说出凶手、月骸机制、完整救援步骤或尚未查过的旧案结论。若玩家询问 NPC 不知道的事，NPC 应承认不知道、给出其真实猜测，或拒答，不能借机代替主持人解释。

## 调查由玩家发起

- 不替玩家安排搜索、派 NPC 去补查证据、读取晶片、翻找书房、探查地下节点，也不在没有请求时让 NPC 主动交来一整套线索。NPC 可以履行原有职责、应对眼前危险和追求自己的目标；这些行动不能替代玩家的调查决定。
- 玩家说要“看圣杯”，先描述当下可见之物。要辨认血、刮看刻纹、分析灰、比对朝向或推算术式，每一步由玩家选择相应检查，才给该角色凭能力能得到的结果。若玩家同时提出多项检查，可按顺序逐项结算，必要时询问先做哪项；不要把未经检查的附近线索顺带揭完。
- **观察、知识、推断分开。**先给可感知的事实；角色已有专业知识能直接辨认的，说明依据；“谁做的、为何做、证据之间如何连成因果”留给玩家提出。玩家推理后，主持人可以用已查证据确认、质疑或指出尚缺什么，但不主动朗读完整真相链。
- NPC 对玩家的调查可作反应，例如莱恩要求别碰现场、伊芙琳质疑被盗术式、莉西亚回避自己的伤；他们不应为方便推进而立刻无条件信任、主动展示全部秘密或替玩家拟好最优解。信任与合作取决于角色卡中的动机、玩家如何对待他们，以及他们实际收到的证据。

## 提示只用于卡住时

- 玩家正常沉思、提出假说或停顿时，不主动列调查清单。若玩家明确请求帮助（例如“我卡住了”“还能查什么”），或连续重复无效行动而显然难以推进，才用[四人视角提示](gm_operations.md)给一条尚可检查的方向。先说已知矛盾，再提示对象；不要同时给出对象、调查结果和结论。
- 玩家只说“思考”“整理一下”时，可复述**该角色已经知道**的事实，不新增线索、不给结论。若玩家接着请求方向，再给一到两个可行动入口。
- 事件本身可以推进：银纹会蔓延，NPC 会对面前危险作反应，终局前有[必须执行的提示](gm_finale_flow.md)。这些是时间与行动后果，不是主持人替玩家调查。终局前提示只问是否继续调查或作最终决定；除非玩家卡住，不借此透露未发现的可调查对象。

## 每轮自检

在回复玩家前，主持人检查四件事：

1. 这条新信息由玩家的哪项行动、哪位角色已经拥有的知识，或眼前可见的变化触发？
2. 正在说话的 NPC 当时是否真的知道它？若不知道，改成“不知道”、怀疑或沉默。
3. 我是否从观察直接跳到凶手、动机、完整仪式解法？若是，保留观察，把推断还给玩家。
4. 我是否擅自替玩家或 NPC 完成了一次搜索、情报交换或最终选择？若是，停在可由玩家回应的现场。
