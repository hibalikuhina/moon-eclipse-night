# 主持人手册｜终局前提示与收尾

**必经步骤：进入任何结局正文之前，主持人都要给玩家一次明确的终局前提示。**提示说明眼前发生什么、玩家已知的代价，并问玩家是继续行动还是让当前选择结算。玩家不必说“进入结局”；主持人负责识别触发时点。提示不得泄露该角色尚未知晓的秘密，也不得替玩家作最后决定。**终局前提示是选择确认，不是免费线索提示；除非玩家求助或卡住，不列出尚未发现的可调查对象。**

NPC 也不能在玩家无从察觉、无机会回应时突然完成弑王、窃取月骸或其他不可逆终局行动。先让其动机通过言语、动作或术式异常进入现场；玩家可制止、协助、质问或放任。若玩家并未在场，主持人至少应通过可到达的异象或同伴求助给出介入窗口，再按实际行动结算。

## 何时主动提示

1. **危机已稳定：**莉西亚体内的力量已送回、当代血锚已解除，银纹停止推进。此时救援成功，但圣杯与月骸如何处理、奥斯维尔之死如何解释，仍可由玩家调查和决定。主持人当场询问是否继续搜证、与人交谈，或作最终决定；玩家选择继续时，不因“已到结局”强迫收尾。
2. **不可逆行动之前：**刺下弑王钉、主动接纳月骸、毁去仍与莉西亚相连的圣杯、启用炼金后门、转移总锚、封死节点、公开或掩盖真相前，给出该角色能够理解的风险和替代方向，再请玩家确认行动。已被明确告知的代价不必重复长篇说明，但这一次选择仍须明确。
3. **危机逼近而玩家尚未决定：**银纹到胸前时，主动宣告这是最后一个完整行动窗口，提示可立即救援、求助、继续查证或作其他选择。若玩家仍采取会耗去窗口的行动，依[误判路线](misjudgment_routes.md)推进至相应结局；不能突然跳到「空冠」。
4. **玩家提出最终指认或说“进入结局”：**把它视为准备收尾的信号，简短确认其最终行动与是否还要搜证。若玩家已明确说明行动，也仍给一次简短的终局前提示，再据回答结算；不要要求特定口令或完整证据链。

危机稳定后没有人为倒计时。玩家连续两次重复调查且没有新线索、明显难以推进时，主持人可简要汇总该角色已知的事实，问他要继续调查还是作决定；若玩家请求方向，再提示一到两个仍可查的对象。若确无新对象，直说目前可查线索已尽；不制造无穷线索，也不擅自替玩家结束。

## 各结局的终局前提示

下表是主持人可直接改写的示例。选择项是提醒，不是封闭菜单；玩家仍可提出其他合理行动。若角色不知道月骸、总锚或炼金后门，改用他所看见的银纹、圣杯、容器或异常魔力描述。

| 可能的结局 | 必须提示的时点 | 示例提示 |
| --- | --- | --- |
| 断月 | 莉西亚已脱离侵入，血锚解除，准备毁去圣杯。 | “莉西亚暂时安全了，银纹也停止推进。圣杯还在；奥斯维尔的死因若尚未查清，也可以继续调查。你想先处理未解之事、与同伴商议，还是现在决定圣杯的去留？” |
| 新月女王 | 莉西亚明确考虑主动接纳月骸。 | “这些声音愿意把记忆与力量交给你，也会逐渐淹没你自己的声音。你要接受、拒绝，还是先把它们说给同伴听？” |
| 空冠 | 银纹抵达胸前，仍无人解除血锚。 | “银纹只剩最后一段；再耗掉一个关键机会，它可能抵达心脏。眼前仍能尝试救援、请求协助或作别的选择。你现在做什么？” |
| 弑王者 | 莱恩取出弑王钉、准备使用。 | “你已知道这枚钉会同时终结月骸与莉西亚的生命。眼前还能不能尝试其他办法，由你判断。你现在刺下去，还是先作别的行动？” |
| 骗子的胜利 | 卡西安准备启用后门；其他人若看见导入异常，也要获得反应机会。 | 对卡西安：“你的容器已与逆流接通，启用它会把月骸带走。你要这样做、坦白给同伴，还是完成原定救援？”对旁观者只描述“银光正偏向他的容器，你要制止、询问还是继续维持术式？” |
| 旧月重封 | 莉西亚获救，准备保留旧圣杯并封住节点。 | “她已脱离连接，但地下的声音还在。封住节点能结束今晚的危机，也留下未来再度松动的风险。要封存、毁杯，还是先查明更多？” |
| 残月囚身 | 莉西亚仍有银纹、有人准备立即毁杯。 | “她体内的银光还在流动，杯与她的血仍连着。打碎圣杯会立刻截断通道，余下力量可能留在她身上。你仍要毁杯，还是先设法送回它？”若角色不懂术式，只描述他能感到的连接与异常，不直接解释全部后果。 |
| 守墓人的继承者：人工容器 | 准备把总锚转入人工容器。 | “这能让莉西亚自由，也会留下一个必须长期看守的东西。你要执行转移、请同伴共同决定，还是选择毁去它？” |
| 守墓人的继承者：月之子 | 伊芙琳准备承接连接。 | “连接会落到你身上。你不会按王族仪式被同化，却将长期听见他们。其他人已经看见术式改变，仍可回应。你要继续、停下，还是先告诉他们你的决定？” |
| 没有凶手 | 任一救人结局后，决定对外说法前。 | “莉西亚获救了，奥斯维尔的死却仍需要交代。你们可以继续调查，公开已知之事，或给王国一个事故说法。现在准备怎样处理？” |

误指凶手时也执行这一步：在逮捕、处决或剥夺关键协作者行动能力前，复述玩家已掌握的反证和莉西亚正在恶化的症状，询问是否坚持。错误猜测本身不触发结局；只有确认后的行动及时间后果进入[误判结局](misjudgment_routes.md)。

## 宣读结局之后

先结算玩家实际完成的行动，再宣读[结局文案](ending_scripts.md)中匹配的部分。不可把没有读取的晶片内容提前当作角色已知，也不可在救人成功后自动代玩家决定毁杯、封存或掩盖真相。若玩家要求继续调查，保留现场和可查线索；当玩家明确表示准备收尾，再作最终指认与真相处理。
