# 主持人档案｜真相时间线

以下是主持人掌握的完整顺序，不是任何 NPC 的开局记忆。NPC 只知道自己角色卡、亲历事件及游玩中实际获悉的部分；玩家调查到相应证据后再逐步揭示。见[主持人首要规则](gm_host_rules.md)。

## 三年前至案发前

十年前，灰塔队触动地下旧节点，遭月骸残留意识与逆流反噬。卡西安的姐姐记录下地下意识的性质，留下来维持撤离通道，死于节点封闭前的魔力冲击。王室随后封存事故记录；奥斯维尔没有亲手谋杀她。

三年前，伊芙琳在禁书库看到“并非为了使龙沉睡”“王族之血”“容器”的残页。奥斯维尔烧毁书页。伊芙琳秘密追查，并创造「月蚀逆流」。

三个月前，卡西安以异国商人身份来到王都。他真实身份是灰塔前首席炼金术师卡西安·阿尔德里克，多年来调查姐姐死于塞勒涅地下遗迹的原因。奥斯维尔与他结成不情愿的合作关系。

两周前，奥斯维尔派人从伊芙琳房间拿走逆流记录，交卡西安改造圣杯。卡西安准备烬百合、龙眠灰，也暗留一条可以把月骸力量导入自己容器的后路。

三天前，奥斯维尔问莱恩：若他看似伤害莉西亚，莱恩会不会相信他。案发当日，他命莱恩若仪式出意外就不要让莉西亚离开祭祀塔；又留下剑柄暗格的应急命令。

## 今夜：误会与提前启动

1. 奥斯维尔先到塔顶检查祭坛。莉西亚按吩咐准备圣杯、银烛和祭服，发现杯底陌生的新刻纹，与叔父争执。奥斯维尔不肯说明计划，命她别碰圣杯，把她赶走。
2. 卡西安持摄政王签署的通行令入塔，参与术式准备。莉西亚与叔父争吵离开后，他做最后校准，将圣杯月纹由朝神像转向窗户。
3. 莉西亚因不信任叔父，独自返回塔顶。她用王族血触发塔门石纹进出，门合上后内闩复位。她发现圣杯已转向窗户、祭坛旁留有灰，便以自己的血试着启动圣杯，想知道叔父隐瞒什么。新逆流术式被提前触发。月骸第一次侵入她的意识，她听见“回来”，又看到陌生的王族记忆。她恐惧地离开，后来只说碰灰后出现症状；受侵蚀的记忆与恐惧令她一开始无法完整说出自己用血启动的一步。
4. 伊芙琳也秘密入塔检查圣杯。她看到转移术式，楼梯上传来脚步便离开，只闻到烧焦的花香。那脚步属于正赶往塔顶的卡西安。卡西安发现异常的提前启动反应，上塔时奥斯维尔尚活着。奥斯维尔命他立刻检查地下节点；卡西安离开。伊芙琳当时闻到的烬百合味来自他的材料。

## 谋杀窗口

5. 月骸已能短暂影响莉西亚，借她之口说塔顶少一支银烛，让守门的莱恩去储藏室。银烛不是关键材料，而是支开守卫的借口。莱恩离岗约五六分钟；莉西亚借血脉通行纹进出，门闩再次落下。莱恩返回时看到锁芯由熟悉的左偏变正，之后以仍在身上的守卫钥匙开门。
6. 莉西亚来到塔顶。奥斯维尔察觉仪式失控，在掌心开始绘制切断术。她一度哭着求“叔叔……救我”。下一瞬，月骸控制她，利用她的王族血及奥斯维尔已展开的术式，将逆流锚点临时改为奥斯维尔，强行抽走其魔力、生命力和守墓人力量。
7. 奥斯维尔胸口无伤，皮下银纹以胸口为中心向四肢扩散，体内力量被抽空。他死前抓住莉西亚，从她仪式披肩的深色金纹内衬扯下一片布料。掌心切断符文只完成一半，并留下记忆晶片。
8. 莱恩敲响警钟。奥斯维尔死于塔顶。莉西亚没有完整、可靠的案发记忆，银纹则沿左手向心脏推进。

## 真凶的判定

直接造成奥斯维尔死亡的是**莉西亚的身体**；当时对行为起决定作用的是侵入她意识的**月骸**。她本人并无主动谋杀叔父的意图。她需要面对私自启动仪式的后果，但不能与月骸的杀人意志等同。她对启动经过的回避与记忆侵蚀交织，不能简单视作清醒地隐瞒谋杀。

卡西安掌握材料与术式，却在谋杀前受奥斯维尔命令离开塔顶。莱恩离岗造成机会，但不知道月骸真相。伊芙琳的魔法结构出现在圣杯上，因为研究被奥斯维尔偷走并由卡西安改造，她并未杀人。
