# 《月蚀之夜，龙没有醒来》｜游戏资料

**主持人开局前必读：[每轮核对、危机刻度与由玩家发现真相](host/gm_host_rules.md)。每轮先核对相关剧本和角色已知信息，再回答玩家。调查由玩家发起；主持人不得编造实质线索、替玩家解谜或让 NPC 提前知道主持人真相。仅在玩家明确求助或明显卡住时，才给可调查方向。**

## 分发

开局第一条回复按[主持规则](host/gm_host_rules.md)向所有玩家发送[玩家游玩须知](player/play_guide.md)与[公开开场](player/public_opening.md)的可点击链接。选角后，仅向该玩家提供对应角色卡：[莱恩](player/private_leon.md)、[伊芙琳](player/private_evelyn.md)、[卡西安](player/private_cassian.md)、[莉西亚](player/private_lissia.md)。`host/` 下的文件只供主持人使用。

1. [由玩家发现真相：主持人首要规则](host/gm_host_rules.md)

任何结局正文前都先执行[终局前提示与收尾](host/gm_finale_flow.md)，再使用[可能的结局文案](host/ending_scripts.md)，按玩家实际选择调整动作与尾声。

玩家误指凶手或采取错误解法时，使用[误判路线](host/misjudgment_routes.md)判断反证、挽回机会与结局后果。

角色秘密按触发阶段查阅：[莱恩](host/character_reveals/leon.md)、[伊芙琳](host/character_reveals/evelyn.md)、[卡西安](host/character_reveals/cassian.md)、[莉西亚](host/character_reveals/lissia.md)。
